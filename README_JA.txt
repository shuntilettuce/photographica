  Photographica / Snapmatica  操作マニュアル（日本語）

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  SNAPMATICA（クライアント専用 / Fabric 1.21.x）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Snapmatica はアイテムを必要としない純粋なクライアント Mod です。
サーバーへの導入は不要で、バニラサーバーや他の Mod 環境でもそのまま使えます。

────────────────────────────────────────────────────────────────────────────────
  ファインダーの起動
────────────────────────────────────────────────────────────────────────────────

  スニーク（デフォルト Shift）を押し続ける
  → 画面に EVF ファインダーが表示されます。

  ・ファインダー切替キー（デフォルト：未割り当て）を割り当てると、
    スニークでファインダーを出す機能の ON / OFF をトグルできます。
    オフにすると通常のスニーク操作（ブロック設置など）が戻ります。

────────────────────────────────────────────────────────────────────────────────
  撮影
────────────────────────────────────────────────────────────────────────────────

  P キー（デフォルト）を押す
  → ミラーアップ → シャッター → フラッシュ の順にエフェクトが入ります。
  → 写真は .minecraft/snapmatica/photos/ に日時付きの PNG で保存されます。

────────────────────────────────────────────────────────────────────────────────
  ファインダー内のスクロール操作（スニーク中のみ有効）
────────────────────────────────────────────────────────────────────────────────

  スクロール              焦点距離（ズームレンズ装着時のみ）8mm〜800mm
  Ctrl  + スクロール      絞り（F値）を変更  F1.4 〜 F22
  Alt   + スクロール      シャッタースピードを変更  30" 〜 1/4000
  Ctrl+Alt + スクロール   フォーカス距離を変更（MF モード時のみ）0.3m〜∞

  ※ スクロールアップ = 絞り開放（F値を下げる）／フォーカスを遠くへ
  ※ 露出モードが Av または P の場合、シャッタースピードは自動（操作不可）

────────────────────────────────────────────────────────────────────────────────
  設定メニュー（設定キー：デフォルト未割り当て）
────────────────────────────────────────────────────────────────────────────────

  ◀ / ▶ ボタンで各項目を変更します。

  ┌────────────────────────────────────────────────────────────────────────────┐
  │ Aperture（絞り）   F1.4 / 2.0 / 2.8 / 4.0 / 5.6 / 8.0 / 11 / 16 / 22   │
  │ Shutter（SS）      30" / 15" / 8" / 4" / 2" / 1" /                        │
  │                    1/2 / 1/4 / 1/8 / 1/15 / 1/30 / 1/60 /                  │
  │                    1/125 / 1/250 / 1/500 / 1/1000 / 1/2000 / 1/4000        │
  │ ISO                100 / 200 / 400 / 800 / 1600 / 3200 / 6400 /            │
  │                    12800 / 25600                                             │
  │ Focus（フォーカス距離） 0.3m 〜 ∞（MF 時の初期値として使用）              │
  │ Exp. Mode（露出モード）  M / Av / Tv / P                                   │
  │ Focus Mode（フォーカスモード）  MF / AF / MOB                              │
  └────────────────────────────────────────────────────────────────────────────┘

────────────────────────────────────────────────────────────────────────────────
  露出モード
────────────────────────────────────────────────────────────────────────────────

  M   マニュアル  絞り・SS ともに手動
  Av  絞り優先    絞りを固定、SS は自動計算
  Tv  SS 優先     SS を固定、絞りは自動計算
  P   プログラム  絞り・SS ともに自動計算

  ※ 露出メーター：ファインダー下部の棒グラフで ±3EV 範囲を表示
    （中央に近いほど適正露出）

────────────────────────────────────────────────────────────────────────────────
  フォーカスモード
────────────────────────────────────────────────────────────────────────────────

  MF   マニュアルフォーカス
         Ctrl+Alt+スクロールで距離を手動変更
         0.3m / 0.5m / 0.7m / 1m / ... / 300m / 350m / ... / 700m / ∞

  AF   オートフォーカス
         画面中央の被写体に毎フレーム自動追従
         フォーカスが合うとレティクルが白→緑に変わる

  MOB  モブ追従フォーカス
         正面 5° 以内にいる最も近い生物に自動追従

────────────────────────────────────────────────────────────────────────────────
  ファインダー表示内容
────────────────────────────────────────────────────────────────────────────────

  左上   装着レンズ名
  右上   フォーカス距離（MF または AF 中、レンズ装着時のみ表示）
         例：「2.5m」「350m」「∞」は非表示
  左下   露出情報：「F2.8  1/250  ISO400  50mm」
  下中央 露出メーター（±3EV）
  中央   フォーカスレティクル（4 本の十字線）

  レティクルの色
    白 ：レンズなし / 絞り F8 以上 / フォーカス距離 ∞ 設定時
    緑 ：フォーカスが合っている（誤差 ±tol 以内）
    黄 ：やや外れている（±tol〜±2.5×tol）
    赤 ：大きくズレている、または空など無限遠を向いている

  ※ tol はフォーカス距離 × 絞り × 0.08 で計算されます

  EVF プレビュー効果（ファインダー内）
    ・露出オーバー/アンダー時に画面が白/黒く傾く
    ・ISO が高いほど画面にノイズが乗る
    ・絞り開放に近いほど周辺減光（ビネット）が強くなる
    ・絞りとフォーカス距離に応じてリアルタイム DoF ぼけプレビュー

────────────────────────────────────────────────────────────────────────────────
  Distant Horizons（DH）対応（1.21.11 ビルドのみ）
────────────────────────────────────────────────────────────────────────────────

  DH を導入していると、MC レンダリング距離外の LOD 地形にも AF が対応します。
  ・DH 未導入時：従来通りの動作（変化なし）
  ・注意：EVF のぼけプレビューは DH 地形には未対応（∞ 扱いのまま）

  PHOTOGRAPHICA（サーバー対応 / Fabric 1.21.x）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Photographica はサーバーに導入するタイプの Mod です。
カメラやフィルム、暗室機器などがアイテム・ブロックとして実装されています。

────────────────────────────────────────────────────────────────────────────────
  アイテム一覧
────────────────────────────────────────────────────────────────────────────────

  カメラ類（ツールタブ）
    ・デジタルカメラ (Camera)            SDカードで写真を管理
    ・ミラーレスカメラ (Mirrorless Camera) デジタルカメラと同様
    ・フィルムカメラ (Film Camera)        フィルムロールを装填して使用
    ・ビデオカメラ (Video Camera)         動画撮影用

  レンズ類（カメラに右クリックで装着）
    ・50mm プライム      標準、軽いぼけ
    ・35mm プライム      準広角
    ・85mm プライム      ポートレート向き
    ・14mm UWA           超広角
    ・24-70mm ズーム     汎用ズーム
    ・70-200mm ズーム    望遠ズーム
    ・100mm マクロ       接写向き

  フィルム類（フィルムカメラ用）
    ・カラーフィルム 400        36枚撮り
    ・カラーフィルム 100        36枚撮り（低感度・高画質）
    ・カラーフィルム 1600       36枚撮り（高感度）
    ・白黒フィルム 400          36枚撮り
    ・カラーフィルム 400（24枚）
    ・露光済みフィルム          撮影後のフィルム
    ・現像液タンク              フィルム現像用（32回使用可能）
    ・現像済みフィルム          現像後のネガ
    ・フォトペーパー            プリント用印画紙
    ・SDカード                  デジタルカメラ用ストレージ
    ・写真 (Photo)              完成した写真アイテム

  ブロック類
    ・暗室 (Darkroom)           フィルム現像 GUI
    ・引き伸ばし機 (Enlarger)   ネガからプリント
    ・プリンター (Printer)      デジタル写真の印刷
    ・フォトフレーム            壁に飾れる額縁
    ・フォトスタンド            床置きスタンド

────────────────────────────────────────────────────────────────────────────────
  デジタルカメラ（Camera / Mirrorless Camera）の使い方
────────────────────────────────────────────────────────────────────────────────

  1. カメラをメインハンドに持つ
  2. 必要に応じてレンズを右クリックで装着
  3. 右クリック → 設定メニューが開く（スニーク中は撮影）
     ※ 設定キーを割り当てると設定メニューを直接開けます
  4. スニーク（Shift）を押し続けるとファインダー表示
  5. ファインダー表示中に 設定キー（デフォルト：未割り当て）で設定メニュー
  6. SDカードを挿入（未割り当てキーで着脱）→ 写真が記録される
  7. SDカードをビューアキーで開いて閲覧

  写真は .minecraft/photographica/photos/ にも自動保存されます。

────────────────────────────────────────────────────────────────────────────────
  フィルムカメラの使い方
────────────────────────────────────────────────────────────────────────────────

  準備
    1. フィルムカメラをメインハンドに持つ
    2. フィルムロールをオフハンドに持ち、右クリックで装填
    3. レンズを右クリックで装着

  撮影
    4. スニーク（Shift）を押し続けてファインダー表示
    5. 設定を調整（スクロール操作は Snapmatica と同様）
    6. スニーク中に 設定キー でシャッター → フィルムが1コマ進む
       ※ ワインドキー（未割り当て）を割り当てるとフィルムを手動で巻けます

  現像
    7. フィルムが全て露光されたらフィルムを取り出す（アンロードキー）
       → 「露光済みフィルム」アイテムになる
    8. 暗室ブロックを設置・右クリック
       → 露光済みフィルム + 現像液タンク を投入 → 現像実行
       → 「現像済みフィルム」になる

  プリント
    9. 引き伸ばし機ブロックを設置・右クリック
       → 現像済みフィルム + フォトペーパー を投入 → プリント実行
       → 「写真」アイテムが完成

────────────────────────────────────────────────────────────────────────────────
  ファインダーとスクロール操作（Photographica）
────────────────────────────────────────────────────────────────────────────────

  ファインダー表示：カメラを持ちながらスニーク
  操作はほぼ Snapmatica と共通です：

  スクロール              焦点距離（ズームレンズのみ）
  Ctrl  + スクロール      絞り
  Alt   + スクロール      シャッタースピード
  Ctrl+Alt + スクロール   フォーカス距離（MF モード時）

────────────────────────────────────────────────────────────────────────────────
  キー設定まとめ（Photographica）
────────────────────────────────────────────────────────────────────────────────

  設定メニューキー       未割り当て（推奨：任意のキー）
  ワインドキー           未割り当て（フィルム手動巻き）
  SDカード装填キー       未割り当て
  SDカード取出キー       未割り当て
  録画停止キー           G（ビデオカメラ）

  ※ 設定 → キー・マウス → Photographica のカテゴリから割り当ててください。

────────────────────────────────────────────────────────────────────────────────
  アーマースタンドへの装着（Photographica）
────────────────────────────────────────────────────────────────────────────────

  カメラをアーマースタンドに装備させると、
  三脚カメラとして遠隔からシャッターを切ることができます。
  アーマースタンドに右クリックで装着 / 設定メニューから遠隔操作。

────────────────────────────────────────────────────────────────────────────────
  共通：写真の保存先
────────────────────────────────────────────────────────────────────────────────

  Snapmatica     .minecraft/snapmatica/photos/YYYY-MM-DD_HH-mm-ss.png
  Photographica  .minecraft/photographica/photos/<UUID>.png
                 ビデオ       .minecraft/photographica/videos/

  露出設定リファレンス

  ┌──────────────────────────────────────────────────────────────────────────┐
  │ F 値（絞り）とボケ量                                                     │

  │   ISO 3200以上  … 目立つノイズ（暗所撮影向け）                          │
  ├──────────────────────────────────────────────────────────────────────────┤
  │ シャッタースピードと手ブレ                                               │
  │   1/60 以下       … 手ブレ警告（WARN Blur 表示）                        │
  │   1/125〜1/500    … 標準的な動体撮影                                    │
  │   1/1000〜1/4000  … 高速シャッター（水しぶき等）                        │

    意図的にオーバー/アンダーにして雰囲気を出すこともできます。
