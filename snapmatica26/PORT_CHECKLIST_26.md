# snapmatica 0.4.0 — MC 26.1.2 移植テスト チェックリスト

26ツリーは 045cdea 時点で止まっていたため、**bdf94d8（レンズ物理）と adc6fe5（アルバムUI・旧版バグ修正）の2コミット分**をまとめて移植した。
そのため「今回初めて26で動く機能」が多い。ビルドは通っているが、**実機での動作確認は一切していない**。

移植の性質上、危険度は次の順:

1. GLSLシェーダ（1.21.11版を丸ごとコピー／uniform名が合っていないと真っ黒か無効果）
2. GUI（26は `GuiGraphicsExtractor` + `extractContents` で1.21.11と別物。手書きで新規作成）
3. GL/深度まわり（名前だけの差なので比較的安全）
4. 純粋な計算（ほぼ確実に動く）

---

## 1. 起動・基本

- [ ] クラッシュせず起動する（mixin適用エラーが出ない）
- [ ] 写真が撮れる（`snapmatica/photos/` にPNGが出る）
- [ ] 動画が録れる（`snapmatica/videos/` にMP4が出る）
- [ ] ログに `[Snapmatica] depth planes: near=… far=…` が出る
      → 出ない場合、深度取得が動いていない（以降のボケ関係は全部無意味になる）

## 2. シェーダ（★最重要・丸ごとコピー）

シェーダは1.21.11版をそのまま持ってきた。`EvfBlurRenderer` が渡す uniform 名と一致していないと、
**ファインダーが真っ黒**か**ボケが一切かからない**という形で出る。

- [ ] ファインダー（スニーク）を覗いてボケがかかる
- [ ] 画面が真っ黒／真っ白にならない
- [ ] F値を変えるとボケ量が変わる
- [ ] ボケの縁が固いリング状でなく、自然な濃淡になっている
- [ ] 遠景（inf）にしたとき遠くがシャープになる

## 3. レンズ物理（bdf94d8 分・26では初）

- [ ] **焦点距離を変えるとF値が勝手に動く**（羽根を動かさない＝口径固定なので）
      例: 50mm F2.8 → 100mm にすると F5.6 付近になる
- [ ] 広角端でF値が下限（F1.4）に張り付き、それ以上は開かない
- [ ] F11以上でもボケが完全にゼロにならない（望遠側で確認）
- [ ] F22など絞り込んだとき、全体がわずかに甘くなる（回折）
- [ ] **8mm など超広角で樽型に歪む / 200mm 以上で糸巻き型にわずかに歪む**
- [ ] 50mm で歪みがゼロ
- [ ] 焦点距離を変えた瞬間に「ボヨン」と2段階で変化しない

## 4. 長時間露光・ブレ（bdf94d8 分・26では初）

- [ ] SSを1/30より遅くすると、複数フレームを合成した写真になる
- [ ] 合成中に画面が固まらない
- [ ] ISO25まで下げられる
- [ ] SS 1s などで歩きながら撮ると、**多重露光でなく連続した流れ**になる
- [ ] 撮影中に暗転しない（ミラーレス動作）

## 5. ピント送り

- [ ] MFのスクロールでピントがゆっくり動く（瞬間移動しない）
- [ ] 5m から inf に飛ばしたとき、カクッとならず連続して抜ける

- [ ] **ガラス越しに構えると、ガラスでなく奥にピントが合う**
- [ ] そのとき奥の景色がボケない（← 1.21.1で見つかった不具合の26版確認）

## 移植時に26だけ違う判断をした箇所

実機で挙動が違って見えたら、まずここを疑う。

| 箇所 | 1.21.x | 26 | 理由 |
|---|---|---|---|
| 射影行列の取得 | `GameRendererInvoker` @Invoker mixin | `gameRenderState.levelRenderState.cameraRenderState.projectionMatrix` | 26は元からこの経路。mixin不要 |
| far plane の第2候補 | `gameRenderer.getFarPlaneDistance()` | `-1f`（不採用） | 26のGameRendererに該当メソッドが無い。射影行列が第1候補なので実害なし |
| Distant Horizons | LODレイキャストにフォールバック | **無し** | DHに26版が無く、依存もしていない。レイキャストが外れたら無限遠のまま（遠景はシャープ＝正しい） |
| ステータス表示 | `player.sendMessage(text, true)` | `mc.gui.setOverlayMessage(…)` | 26に `displayClientMessage` が無い |
| ボタン描画 | `ButtonWidget#drawIcon`/`drawLabel` | `Button#extractContents` | 26は `Button` が abstract、`extractContents` が描画フック |
| 画面背景 | `renderBackground` を空にして `render` から描く | 同左（`extractRenderState` から） | 26の `Screen.extractRenderState` は背景を呼ばないので実は不要だが、1.21.x と作りを揃えた |
